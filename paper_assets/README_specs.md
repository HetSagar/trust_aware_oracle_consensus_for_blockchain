# Paper assets: figures and tables for the Springer LNCS paper

Everything here is generated by `python paper_assets/build_assets.py` from the saved results in
`results/final/` and `analysis/out/`. **Never retype a number by hand.** If a result changes, rerun the
script. Numbering matches the **10-page Final Working Draft**: Figs. 1–3 and Tables 1–8 go in the paper;
Fig. S1 and Tables S1–S4 go in the supplementary material.

## LNCS rules applied

From Springer's *Guidelines for Authors of Proceedings* (Computer Science), as published with recent
LNCS calls for papers:

| Rule | How these files meet it |
| --- | --- |
| Vector graphics preferred for diagrams and charts | Every figure is supplied as PDF (fonts embedded, TrueType) and EPS, plus SVG |
| Raster line art at least 800 dpi, preferably 1200 dpi | PNG versions are 1200 dpi |
| Lettering in figures no smaller than 6 pt | Figures use 7–8 pt Times-style (STIX) text at their natural size |
| Printed volumes are black and white; colour figures must stay legible in grayscale | Every series has its own marker and line style as well as colour; all figures were checked in grayscale |
| Figure captions **below** the figure, table captions **above** the table, 9 pt | Captions are not inside the images; they are in `captions.md`, in each `.tex` table and in the Word file |
| Captions that are not full sentences take no period | Applied in `captions.md` |
| No colour in tables | Tables are black on white, horizontal rules only |
| Cross-reference every figure and table in the text | The draft text cites each one (e.g. "Table 7 shows …") |
| Font: LaTeX uses CMR, Word uses Times | LaTeX tables inherit the document font; Word tables use Times New Roman |

The LNCS text area is 122 mm × 193 mm. The fit check (`preview/lncs_preview.pdf`) sets every figure and
table on a page of that size, in 10 pt type with 9 pt captions. The page-budget check
(`preview/final10_budget.pdf`) sets the whole 10-page draft text with Figs. 1–3 and Tables 1–8 and the
references: **10 pages**. The official `llncs.cls` could not be downloaded in this environment, so the
layout is emulated. Run one final check in the real template.

**Word** (Springer LNCS Word template): Insert → Pictures → the `.png` (or `.svg` in Word 365). Right-click

paragraph *below* the figure using the template's figure-caption style.

**LaTeX**: add `\usepackage{booktabs,array,tabularx,makecell}` to the preamble, then `\input{tables/tab06_main.tex}`
where the table belongs. Each file already contains its caption (above) and label (`tab:main` etc.).
For the supplementary document, number tables and figures as S1, S2, … with

```latex
\renewcommand{\thetable}{S\arabic{table}}
\renewcommand{\thefigure}{S\arabic{figure}}
```

**Word**: open `tables/tables_for_word.docx` (main Tables 1–8 first, then a "Supplementary tables"
heading with S1–S4), copy a table together with its caption and note into the LNCS Word template, then
apply the template's table-caption style to the caption line. Table text is 8 pt Times (Table 1: 7.5 pt; Table 2: 9 pt),
and column widths are set to fit 122 mm.
